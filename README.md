# Чат-бот на JavaScript
Учебный проект — интерактивный чат-бот в браузере. Умеет здороваться, запоминать имя пользователя, принимать числа (включая диапазоны и переменные), выполнять арифметические операции и хранить последний результат.

## Возможности

- **Чат в реальном времени** — сообщения пользователя и бота появляются в ленте.
- **Знакомство** — команда `/name` запоминает имя и приветствует пользователя.
- **Ввод чисел** — поддерживаются:
  - одиночные числа: `2, 3`
  - диапазоны: `10...13`, `1..5`
  - смешанный ввод: `7, 10...13, 15`
  - переменные: `x`, если сохранена через `/set`
  - последний результат: `ans`
- **Арифметика** — `+`, `-`, `*`, `/`, `min`, `max`, `avg`, `gcd` (НОД).
- **Переменные** — команда `/set x = 5` сохраняет значение и позволяет использовать его в `/numbers`.
- **`ans`** — ссылка на последний результат вычислений.
- **Анимация «бот печатает»** — три мигающие точки перед ответом.
- **Выбор операции через radio-кнопки** — после ввода чисел.
- **Команда `/stop`** — завершает сессию.

## Быстрый старт

## Команды
- **/start - Начать общение - Пример: /start
- **/name <имя>	- Представиться боту - Пример: /name Аня
- **/numbers <числа>	Ввести числа для операции -	Пример: /numbers 2, 3
- **/set <имя> = <число> - Сохранить переменную -	Пример: /set x = 5
- **/stop -	Завершить работу -	Пример: /stop

  ## Форматы чисел в /numbers
- Одиночные числа	Пример: /numbers 2, 3 Результат: [2, 3]
- Диапазон	Пример: /numbers 10...13 Результат: [10, 11, 12, 13]
- Смешанный	Пример: /numbers 7, 10...13, 15 Результат: [7, 10, 11, 12, 13, 15]
- Переменная	Пример: /numbers x, 10 Результат: [5, 10] (если x = 5)
- Последний результат	Пример: /numbers ans, 10 Результат: [<предыдущий>, 10]

  ## Доступные операции
- '+'	- Сумма всех чисел
- '-'	- Последовательное вычитание
- '*' - Произведение
- '/'	- Последовательное деление
- 'min' - Минимум
- 'max'	- Максимум
- 'avg' - Среднее арифметическое
- 'gcd' -	Наибольший общий делитель
